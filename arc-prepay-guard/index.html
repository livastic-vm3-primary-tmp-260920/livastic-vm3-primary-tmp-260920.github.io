Evidence limits and next steps

    Exactly what is read

    • Live eth_chainId and eth_blockNumber from Arc mainnet RPC; the tool refuses a network other than chain 5042.
    • ERC-8004 identity ownerOf(agentId) and tokenURI(agentId) from the canonical Arc identity registry (0x8004A169...39a432). An on-chain JSON data: registration can be decoded locally; external registration URLs are never fetched automatically.
    • Canonical Arc reputation getClients(agentId) and getSummary(agentId, clients, "", "") using the unfiltered public client list (up to 64 entries). This is not a sybil-resistant allow-list or independently verified payer evidence.
    • No signing RPC, wallet connection, trusted-decision API, private network scans or untrusted external profile downloads. All on-chain metadata is rendered as inert text. Only the official Arc RPC is in the page's network allow-list.
