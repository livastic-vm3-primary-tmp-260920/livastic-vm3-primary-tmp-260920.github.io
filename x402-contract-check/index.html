Key 2026 implementation detail

x402 v1 vs v2 is not just renaming the header

v1 may put maxAmountRequired and outputSchema in accepts[0] with old network identifiers. A buyer that blindly interprets those fields as v2 can quote or pay incorrectly.

v2 uses the base64 PAYMENT-REQUIRED header, the accepts[*].amount atomic token amount, CAIP-2 chain identifiers such as eip155:8453, and a top-level resource. Bazaar discovery lives in extensions.bazaar, not the v1 outputSchema field.

The Bazaar metadata schema validates its discovery info. An output: {type,example} declaration alone is not the JSON Schema for all actual paid response fields, required/nullability or error outcomes.
