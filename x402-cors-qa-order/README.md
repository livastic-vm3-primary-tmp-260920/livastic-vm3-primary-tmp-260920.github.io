# One Cursor — optional manually agreed paid CORS QA (one human owner)

The public page `index.html` is a **buyer preflight and written-scope enquiry**, not an automatic payment checkout. A prospective external developer must request a quote by email, and the original seller must confirm exact scope, timeline, acceptance and payment/refund terms **before any transfer**. Only then may the independent buyer choose to send real native Circle USDC on Base mainnet to the original one-owner verified historic VM5 receiver. There is no wallet connection or transaction signing on this page.

The direct settlement recipient is NOT the VM1 MetaMask address. Its original backup is not independently verified, so this service does not ask anyone to pay it. No existing seller/machine wallet was changed, consolidated or moved.

The free MIT x402 Browser Readiness Check and its separately original platform-managed $1.50 Soul.Markets machine-paid service remain fully optional and independent. The $15 custom report is for a different human buyer requirement: one authorized **public** GET/POST x402 endpoint, one browser Origin, one framework/proxy, a risk-limited CORS/headers matrix, recommended code sketch, and two local regression acceptance checks. No live code changes, wallet payments, private source work, audited contract, facilitator settlement, paid retry or exploit test is included. The fee buys a service, not exclusive rights over MIT software.

The synthetic sample output is produced entirely offline by existing original `x402-smokecheck/checker.mjs` v1.0.1 with fictional header names/values: `synthetic-example-report.json` contains two blockers and two warnings and is NEVER called a client case, sale or endorsement.

Revenue starts at **zero** for this product. Page metrics, emails and wallet quote descriptions are not settlement. Unique external buyer payments are counted only after the VM5-original read-only Base native Circle USDC receipt watcher independently verifies the actual transfer and matches it to written scope/order. Bank fiat conversion and after-expense profit are separately unknown.
