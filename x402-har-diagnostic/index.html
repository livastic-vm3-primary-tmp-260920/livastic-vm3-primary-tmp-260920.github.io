What this tool can — and cannot — establish

  • Can: highlight a missing or hidden PAYMENT-REQUIRED response header, an observed OPTIONS mismatch, an unsigned 400/422, a signed retry receiving 402, and v1/v2 metadata shapes.
  • Cannot: know whether money reached the payee, whether the quoted USDC asset is authentic, or whether a paid resource was delivered. HTTP 2xx is not a chain receipt. Some CORS requests never appear in a captured HAR.
  • Privacy model: no analytics, fetch, SDK, CDN, cookies, localStorage, wallet provider or server-side processing. The analyzer returns authored codes and integer counts only. You can inspect the open-source implementation.
